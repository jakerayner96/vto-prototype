# Virtual Stylist (VTO) prototype

The Virtual Try On journey as the **Virtual Stylist** entry point, built for all seven fascias: Debenhams, boohoo, boohooMAN, PrettyLittleThing, Karen Millen, Dorothy Perkins and Coast. No build step.

- **Review shell:** `index.html` — the same dark Group-UX chrome as the PLP and Core PDP configurators (window controls on top, navigation down the left). No configuration: the left panel is the fascia list, the journey steps (click to jump), the live product and notes. Fold view = iOS Safari frame.
- **Page:** `vto.html?brand=<key>[&step=<step>]` — PDP + the Virtual Stylist flow for one fascia. Brand keys: `debenhams boohoo boohooman plt karenmillen dorothyperkins coast`. Steps: `pdp intro camera review loading result bag limit`.
- **Config:** `brands.js` — one entry per fascia: tokens, font, theme (dark/light sheet), USP copy, Deliver+ lockup, product (name, price, sizes with stock, images, result image, live URL).
- **Repo:** github.com/jakerayner96/vto-prototype · **Pages:** jakerayner96.github.io/vto-prototype

```
python3 -m http.server 8000     # from the repo root; assets need HTTP, not file://
```

Camera access needs HTTPS: open the Pages URL on a phone (Add to Home Screen for full-screen), or `npm run tunnel` while iterating. Without a camera the flow demos with the design's bodyshot.

## The journey

PDP (fascia chrome, live product) → **Virtual Stylist** chip → **Add a Photo** sheet: helper copy, 18+ consent checkbox (a legal record, it does not gate the buttons), "Max 5 try-ons per day. Images generated by AI" → native Camera (real `getUserMedia`) or Upload (native picker) → Review (Retake / Use Photo) → Analysing your photo… → Creating your outfit… (3–6s each, randomised) → **Result**: full-bleed look with the fascia watermark, size row, Add to bag; close + share rail → Add to bag closes the overlay, ticks the bag counter and slides the Added to Bag sheet up over the PDP.

- **Five try-ons a day.** Each generation spends one; the sheet note counts down ("4 try-ons left today"); the loading screen carries "n of 5 today". A sixth attempt raises the daily-limit modal. One photo per try-on: there is no Add Another Photo, no multi-look canvas and no Virtual Wardrobe / account section any more.
- Once a look exists the chip carries a count badge and reopens the result. Closing mid-generation keeps it running; when it finishes a toast offers View.
- The "generated" result is the product's own full-length model shot (boohoo keeps the real generated jersey look from the Figma file). Nothing is generated for real.

## Structure

```
index.html        review shell (fascia list, journey steps, iOS frame)
vto.html          the page: PDP + Virtual Stylist overlay
brands.js         per-fascia config
assets/icons      Figma-exported glyphs, preserveAspectRatio stripped, always in square boxes
assets/brands     fascia logo SVGs (from debenhamsgroup.design/assets/brands)
assets/deliver    SEEL Deliver+ lockups per fascia
assets/products   product imagery per fascia
assets/img        bodyshot.png (camera fallback), result-jersey.png (the Figma generated look)
```
